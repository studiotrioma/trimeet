# TriMeet

Compartilhamento de tela entre amigos, direto de PC para PC.

## Instalar (cada amigo, uma vez)

1. Extraia o `.zip` e rode `TriMeet-Instalador-2.0.exe`.
2. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.

Não precisa de Tailscale, de IP nem de conta.

## Usar

1. Abra o TriMeet e digite **seu nome**.
2. Digite o **código da sala**. Todos precisam usar o mesmo código.
   - O dado ao lado do campo gera um código aleatório.
   - O app lembra o nome e o código para as próximas vezes.
3. Clique em **Entrar**.
4. Para mostrar sua tela, clique em **Compartilhar** (barra de baixo), escolha o monitor ou a janela e clique em **Transmitir**.
5. Para assistir, passe o mouse sobre a tela de um amigo: aparecem os botões de volume, destacar e tela cheia. Duplo clique também abre em tela cheia.
6. O ícone de gráfico mostra FPS, ping e Mbps de cada transmissão.

## Dicas

- Se travar, baixe a qualidade para 8 Mbps ou 720p.
- Com o Discord aberto, desligue **Som do PC** quando não precisar do som do jogo. Assim seus amigos não ouvem a própria voz com atraso.
- O código da sala aparece na barra do topo. Clique nele para copiar e mandar para alguém.
